# Backlog / Планируемые доработки

## Высокий приоритет

### 1. Глобальный медиаплеер
- Плеер фиксируется внизу страницы (persistent, как в Spotify/YouTube Music)
- Работает на всех страницах без прерывания при навигации
- Плейлисты: создание, редактирование, очередь воспроизведения
- Поддержка аудио и видео файлов с сервера
- Управление: play/pause, prev/next, shuffle, repeat, громкость, прогресс-бар
- Мини-плеер и развёрнутый режим

### 2. Улучшенный UI загрузки по URL
- Переработать модалку/страницу загрузки с URL
- Превью ссылки (метаданные, обложка, название)
- Отображение прогресса скачивания в реальном времени
- Поддержка пакетной загрузки (несколько URL сразу)
- История URL-загрузок
