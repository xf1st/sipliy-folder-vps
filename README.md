# Sipliy Folder VPS 🚀

Личный мощный менеджер загрузок на базе VPS. Закидываешь ссылку или видео — сервер качает на высокой скорости (до 1 Гбит/с), конвертирует при необходимости через `yt-dlp` и позволяет скачивать файлы на ПК или просматривать прямо в браузере.

Дополнительно в комплекте:
- **Браузерное расширение (Chrome / Edge / Brave / Opera)**: контекстное меню, отправка ссылок в один клик, отслеживание прогресса и авто-скачивание файлов на локальный ПК.
- **Telegram бот**: возможность отправлять ссылки/файлы прямо в Telegram бот для скачивания на VPS.
- **VirusTotal**: автоматическая/ручная проверка скачанных файлов на вирусы.
- **Push-уведомления (VAPID)**: браузерные push-уведомления при завершении загрузок.

## 🛠️ Стек технологий

| Компонент | Технология |
|-----------|-----------|
| **Backend** | Node.js (CommonJS, Express 5) |
| **Движок загрузок** | aria2c (JSON-RPC) + yt-dlp (для медиа/видео) |
| **Авторизация & Сессии** | `express-session` + `session-file-store` |
| **Конфигурация** | `dotenv` (переменные окружения `.env`) |
| **Уведомления** | `web-push` (VAPID) |
| **Telegram** | Telegram Bot API |
| **Файловый менеджер** | Multer, Archiver (ZIP), ExcelJS (экспорт) |
| **Деплой & Сервер** | SSH2, systemd, Nginx, Let's Encrypt (Certbot) |

## 🔑 Переменные окружения (`.env`)

Все секретные ключи, токены и порты вынесены в файлы окружения.

### Основные переменные

| Переменная | Описание | Значение по умолчанию / Пример |
|------------|----------|--------------------------------|
| `PORT` | Порт веб-сервера Node.js | `3000` |
| `TG_TOKEN` | Токен Telegram-бота из @BotFather | `8981938565:AAGrVbZ...` |
| `TG_BOT_NAME` | Имя пользователя Telegram-бота | `SiplyiFolderUpload_bot` |
| `VT_API_KEY` | API-ключ VirusTotal | *(ваш API ключ)* |
| `VT_API` | URL API VirusTotal | `https://www.virustotal.com/api/v3` |
| `ARIA2_URL` | Адрес RPC сервера aria2 | `http://localhost:6800/jsonrpc` |
| `ARIA2_TOKEN` | Секретный токен aria2 RPC | `mySecretToken123` |
| `DOWNLOADS_ROOT` | Папка скачанных файлов на сервере | `/var/downloads` |
| `BASE_DIR` | Корневая директория данных сервиса | `/opt/vps-downloader` |

## 🚀 Настройка и деплой на VPS (Aeza)

### 1. Локальная подготовка (на ПК)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/xf1st/sipliy-folder-vps.git
   cd sipliy-folder-vps
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Создайте файл `deploy.config.js` в корне проекта (он защищен `.gitignore`):
   ```javascript
   module.exports = {
     host: '77.73.135.98',    # IP вашего VPS на Aeza
     port: 2222,              # Порт SSH (обычно 22 или 2222)
     username: 'root',        # Пользователь
     password: 'ВАШ_ПАРОЛЬ'   # Пароль от VPS
   };
   ```

4. Создайте локальный файл `.env` на основе шаблона:
   ```bash
   cp .env.example .env
   ```
   Укажите в `.env` ваши актуальные токены Telegram и VirusTotal.

---

### 2. Запуск авто-деплоя

Запустите скрипт деплоя:
```bash
node deploy-systemd.js
```

Скрипт автоматически:
- Подключится по SSH к вашему VPS.
- Скопирует модули `app/`, `package.json`, `extension.zip` и файл `.env`.
- Установит права доступа `chmod 600` на `.env`.
- Выполнит `npm ci --omit=dev`.
- Перезапустит системный сервис `vps-downloader` и выведет статус.

---

### 3. Ручное редактирование `.env` на VPS

Если вам нужно изменить токены прямо на сервере Aeza:

1. Подключитесь по SSH:
   ```bash
   ssh -p 2222 root@77.73.135.98
   ```
2. Откройте файл `.env`:
   ```bash
   nano /opt/vps-downloader/.env
   ```
3. Сохраните изменения (`Ctrl+O`, `Enter`, `Ctrl+X`) и перезапустите службу:
   ```bash
   systemctl restart vps-downloader
   ```

## ⚠️ Правила безопасности (Must Know)

1. **Никогда не коммитьте личные ключи в Git!**
   - Файлы `.env`, `.env.local`, `deploy.config.js`, `info_about_vps.txt` должны находиться в **[.gitignore](file:///e:/GitHub/xf1st/sipliy-folder-vps/.gitignore)**.
2. **Безопасность прав доступа на сервере**:
   - Файл `/opt/vps-downloader/.env` должен иметь права `600` (`chmod 600 /opt/vps-downloader/.env`), чтобы другие пользователи сервера не могли прочесть токены.
3. **Пароли учетных записей**:
   - При первом запуске измените стандартный пароль учетной записи администратора в системе.
4. **Смена SSH порта**:
   - По умолчанию Aeza или ваша конфигурация может использовать порт SSH `2222`. Всегда проверяйте порт перед деплоем.

## 🧩 Браузерное расширение

### Установка:
1. Откройте страницу расширений в браузере (`chrome://extensions` или `edge://extensions`).
2. Включите **Режим разработчика** (Developer mode).
3. Нажмите **Загрузить распакованное** (Load unpacked) и выберите папку `extension/`.

### Подключение к VPS:
1. Зайдите в веб-панель вашей качалки → **Настройки** → скопируйте **Токен для расширения**.
2. Откройте попап расширения в браузере, укажите URL сервера (например: `http://77.73.135.98:3000`) и вставьте токен.
3. Готово! Теперь вы можете кликать правой кнопкой мыши по любой ссылке или медиа и выбирайте «Скачать на VPS».

## 📊 Основные API Эндпоинты

| Метод | Эндпоинт | Назначение |
|-------|----------|------------|
| `GET` | `/api/downloads` | Получить список активных и завершенных загрузок |
| `POST` | `/api/add` | Добавить ссылку на скачивание (HTTP / Magnet / Torrent) |
| `POST` | `/api/downloads/:gid/pause` | Поставить загрузку на паузу |
| `POST` | `/api/downloads/:gid/resume` | Возобновить загрузку |
| `DELETE` | `/api/downloads/:gid` | Удалить загрузку |
| `GET` | `/api/files` | Список готовых файлов в хранилище |
| `DELETE` | `/api/files/:file` | Удалить файл |
| `GET` | `/api/vt/:file` | Проверить файл через VirusTotal |
| `POST` | `/api/add-ext` | **[Bearer Token]** Добавить загрузку из браузерного расширения |
