## 🔴 P0 — Превью видео (основная проблема)

### [ ] BUG-1: Видео в превью показывает `00:00` и чёрный экран
**Где:** боковая панель превью + полноэкранный медиа-вьювер
**Симптом:** `ShadowFiend [0EaYlwZ5-k8].mp4` → плеер `00:00 / 00:00`, не играет.
`furina-...mp4` (4 сек) → играет нормально.

**Гипотеза A (главная):** в `openPreview`/`openMediaViewer` для видео генерируются
4 тега `<source>` с `quality=720/480/360`. Транскод-варианты идут через ffmpeg
pipe с `-movflags frag_keyframe+empty_moov` — **у потока нет длительности и нет
Range** → плеер показывает `00:00`, перемотка не работает. Если Plyr/браузер
выбирает не оригинал (size=1080), а транскод — видео «висит».
- `app/server.js:1746-1779` — транскод-ветка
- `app/templates.js:2801` (openPreview) и `:2916` (mediaViewer) — `<source>` теги

**Гипотеза B:** имена с `[` `]` ломают URL где-то в цепочке (но `encodeURIComponent`
вроде корректен — проверить реальный запрос в Network).

**Фикс (план):** для локальных файлов отдавать ТОЛЬКО оригинал с Range
(один `<source>` без quality-вариантов), либо чинить транскод чтобы отдавал
duration. Оригинал с Range играется мгновенно и с перемоткой.

### [ ] BUG-2: Превью видео не перематывается
Следствие BUG-1 — транскод-поток без Range. После фикса BUG-1 проверить перемотку.

## 🟠 P1 — Подключение / загрузка

### [ ] BUG-3: «Нет связи с VPS» (ложные срабатывания или обрывы)
**Где:** индикатор в шапке.
**Код:** `checkConnection()` в `app/templates.js:1849` — `fetch /api/speedtest/ping`
с таймаутом 4.5с, опрос каждые 15с.
**Проверить:**
- Не слишком ли мал таймаут 4.5с на новом домене?
- SSE-соединение `/api/events` через nginx `.online` — не рвётся ли?
  (nginx уже с `proxy_buffering off`, но проверить `proxy_read_timeout`)
- Реальные обрывы vs ложные — глянуть Network при появлении индикатора.

### [ ] BUG-4: «Загрузка...» зависает в «Мои файлы»
**Где:** список файлов иногда не подгружается, висит «Загрузка...».
**Код:** `navigateTo` → `loadDir` → `fetch /api/fm/list` в `app/templates.js`.
**Проверить:**
- Сессионная cookie на новом домене (`sameSite:lax`, не `secure`) — не слетает ли?
- Падает ли `/api/fm/list` с ошибкой (Network)?
- Нет ли таймаута от nginx при медленном ответе.
