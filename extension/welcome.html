Добро пожаловать в Sipliy Folder VPS

Скачивайте файлы с любых сайтов прямо на ваш VPS — правым кликом по ссылке. Файлы потом загружаются с сервера на максимальной скорости 1 Гбит/с.

1 Получите токен на сайте

Войдите в веб-интерфейс Sipliy Folder VPS и получите личный токен:

Откройте https://sipliyfolder.ru → войдите → нажмите ⚙ Настройки в меню справа сверху → раздел Токен для расширения → нажмите кнопку Показать → скопируйте токен.
🌐 Открыть сайт

2 Введите данные в расширение

Кликните на иконку Sipliy Folder VPS в правом верхнем углу браузера (рядом со строкой адреса) и заполните два поля:

  • URL сервера — например https://sipliyfolder.ru
  • Токен — тот, что вы скопировали на шаге 1

Нажмите Проверить, чтобы убедиться, что всё работает, затем Сохранить.

💡 Не видите иконку? Кликните на значок 🧩 (пазл) в браузере → найдите «Sipliy Folder VPS» → нажмите 📌 (булавку), чтобы закрепить.

3 Используйте

Найдите ссылку на любой странице, кликните по ней правой кнопкой мыши и выберите один из пунктов:

  • Скачать ссылку на VPS — для обычных <a href> ссылок
  • Скачать изображение на VPS — на любой картинке
  • Скачать видео на VPS — на встроенном видео или аудио
  • Скачать эту страницу как файл на VPS — клик по пустому месту страницы
  • Скачать выделенный URL на VPS — выделите URL текстом и кликните правой кнопкой
После клика появится уведомление, а на иконке расширения мигнёт зелёная галочка ✓ — значит загрузка добавлена. Откройте сайт, чтобы посмотреть прогресс и забрать готовый файл.
