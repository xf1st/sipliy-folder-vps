# Sipliy Folder VPS — браузерное расширение

Расширение для **Google Chrome** и **Microsoft Edge** (а также любых Chromium-браузеров: Brave, Opera, Vivaldi).

Позволяет правым кликом по любой ссылке отправлять её на ваш VPS — файл скачивается на скорости 1 Гбит/с, а потом вы забираете его с сервера.

## Установка

1. Скачайте/склонируйте папку `extension/`.
2. Откройте в браузере: `chrome://extensions` (Chrome) или `edge://extensions` (Edge).
3. Включите **Режим разработчика** (переключатель в правом верхнем углу).
4. Нажмите **Загрузить распакованное расширение** и выберите папку `extension/`.
5. После установки автоматически откроется страница с инструкцией.

## Что делать дальше

Следуйте инструкции на открывшейся странице (`welcome.html`):
1. Получите токен на сайте → ⚙ Настройки → Токен для расширения → Показать
2. Кликните на иконку расширения, введите URL сервера и токен → Проверить → Сохранить
3. Кликайте правой кнопкой на любой ссылке → «Скачать на VPS»

## Регенерация иконок

```bash
node gen-icons.js
```

Создаёт `icons/icon-{16,32,48,128}.png` с буквой "S" на фиолетовом градиенте.

## Структура

```
extension/
├── manifest.json       # Манифест MV3
├── background.js       # Service worker: контекстные меню, отправка на сервер
├── popup.html          # UI настроек (клик по иконке)
├── popup.js            # Логика настроек + проверка соединения
├── welcome.html        # Приветственная страница (открывается при установке)
├── gen-icons.js        # Генератор PNG-иконок
└── icons/              # Иконки расширения
```

## Возможности

- ✓ 5 типов контекстных меню: ссылки, картинки, видео/аудио, страницы, выделенный текст
- ✓ Поддержка `http://`, `https://`, `magnet:`
- ✓ Бейдж на иконке: `!` если не настроено, `✓`/`!` после операции
- ✓ Уведомления Chrome о статусе
- ✓ Таймаут 10 секунд при отправке
- ✓ Кнопка «Проверить соединение» в popup
- ✓ Полная совместимость Chrome + Edge (Manifest V3)
