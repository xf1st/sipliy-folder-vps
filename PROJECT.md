# Sipliy Folder VPS — полное описание проекта

> Версия сайта: **2.19.0** · Расширение: **2.16.1** · Обновлено: июнь 2026

Личное облако + менеджер загрузок на VPS. Сервер качает файлы на скорости 1 Гбит/с (прямые ссылки, торренты, YouTube и 1000+ сайтов через yt-dlp), хранит их в персональном файловом менеджере, а ты забираешь их на ПК из браузера, через расширение Chrome или Telegram-бота.

---

## Архитектура

```
                    ┌──────────────────────── VPS (Ubuntu 24.04) ───────────────────────┐
                    │                                                                    │
 Браузер ◄──HTTPS──►│  nginx ──► Node.js/Express (порт 3000, PM2)                       │
                    │              │                                                     │
 Расширение ◄─CORS─►│              ├── aria2c (JSON-RPC :6800) — HTTP/magnet загрузки    │
                    │              ├── yt-dlp + ffmpeg — YouTube/медиа                   │
 Telegram ◄────────►│              ├── Telegram Bot API (long polling)                  │
                    │              └── /var/downloads/<user>/ — файлы пользователей     │
                    └────────────────────────────────────────────────────────────────────┘
```

## Возможности

### Загрузки
- **HTTP/HTTPS/FTP/magnet** через aria2c — мультипоточная закачка
- **YouTube и 1000+ сайтов** через yt-dlp: видео (выбор качества 360p–4K) или MP3
- **Прогресс в реальном времени** — SSE-события вместо опроса (с версии 2.19.0)
- **Очередь и история** — активные и завершённые задания с фильтрацией ошибок
- **Cookies для возрастных видео** — загрузка персонального cookies.txt на пользователя

### Файловый менеджер
- Просмотр (список/сетка), поиск, сортировка, breadcrumb-навигация
- Загрузка с ПК: drag & drop, мультивыбор, прогресс со скоростью и ETA
- **Разрешение конфликтов имён**: заменить / пропустить / сохранить оба (`файл (2).ext`)
- Превью: изображения, видео (Plyr, выбор качества), аудио (плеер в сайдбаре), PDF, код с подсветкой, DOCX/XLSX, архивы
- Текстовый редактор прямо в браузере
- Операции: переименование, перемещение (drag & drop), удаление, ZIP-архив папки
- Публичные ссылки: пароль, лимит скачиваний, срок жизни, QR-код

### Уведомления
- **Web Push** (с 2.19.0) — пуш о завершении загрузки даже с закрытой вкладкой (VAPID + Service Worker)
- Браузерные Notification API + звук при завершении
- Уведомления расширения Chrome с авто-скачиванием файла на ПК

### Пользователи и безопасность
- Мультипользовательский режим, изолированные папки, админ-панель
- Пароли PBKDF2 (100k итераций), brute-force защита с экспоненциальным лок-аутом
- **Дисковые квоты на пользователя** с принудительной проверкой при загрузке
- SSRF-защита для URL-загрузок (блок приватных IP, localhost, metadata)
- Защита от path traversal (`fmResolve`), запрет загрузки HTML/JS/SVG
- VirusTotal-проверка файлов
- Авто-удаление старых файлов (1/3/7/30 дней / никогда) на пользователя

### Интеграции
- **Расширение Chrome/Edge** (MV3): правый клик → скачать на VPS, кнопка на YouTube, перехват загрузок, синхронизация темы с сайтом
- **Telegram-бот**: отправь файл боту — он сохранится в твоё облако (лимит размера настраивается)
- Спидтест браузер↔VPS

### UI
- Тёмная/светлая тема, 12 акцентных цветов + свой, синхронизация между сайтом и расширением
- Material 3 Expressive дизайн, мобильная версия с нижней навигацией
- Чейнджлог-модалка при обновлении версии

## Реал-тайм: как работает SSE

```
yt-dlp/aria2 меняет статус задания
  → media.js: sse.emit(username, 'jobs', {...})
  → GET /api/events (открытое SSE-соединение клиента)
  → браузер: EventSource.addEventListener('jobs') → loadTransfers()
```

- Keepalive-пинг каждые 25 секунд, `X-Accel-Buffering: no` для nginx
- Реконнект с экспоненциальным backoff (2с → 30с)

## Web Push: как работает

1. При первом запуске сервер генерирует VAPID-ключи → `vapid.json`
2. Браузер регистрирует `sw.js`, в настройках пользователь жмёт «Включить Push»
3. Подписка сохраняется в `push-subs.json` (по пользователям)
4. Завершение задания → `global._pushJobDone(job)` → `webpush.sendNotification()` всем подпискам пользователя
5. Протухшие подписки (HTTP 410) автоматически удаляются

## Хранилище данных (JSON-файлы в `/opt/vps-downloader/`)

| Файл | Содержимое |
|------|-----------|
| `users.json` | Пользователи: PBKDF2-хэши, метки, права админа |
| `settings.json` | Настройки на пользователя: retention, квота, акцент, лимит TG |
| `tokens.json` | Bearer-токены расширения |
| `shares.json` | Публичные ссылки: пароли, лимиты, сроки |
| `media-jobs.json` | Задания yt-dlp/aria2: статус, прогресс, ошибки |
| `uploads.json` | Реестр загруженных с ПК файлов |
| `activity.json` | Лог действий (последние 200) |
| `tg-users.json` | Связки Telegram chat_id ↔ пользователь |
| `vapid.json` | VAPID-ключи Web Push |
| `push-subs.json` | Push-подписки браузеров |

Запись через `writeJsonAtomic` (tmp + rename) — защита от обрыва при падении процесса.

## Основные API-эндпоинты

### Загрузки
| Метод | Путь | Описание |
|-------|------|---------|
| `POST` | `/api/fm/url-download` | Добавить загрузку (URL/magnet/YouTube) |
| `GET` | `/api/fm/media-jobs?scope=active\|history` | Задания пользователя |
| `DELETE` | `/api/fm/media-jobs/:id` | Отменить задание |
| `GET` | `/api/downloads` | Активные aria2-загрузки |
| `POST` | `/api/downloads/:gid/pause` / `resume` | Управление |
| `GET` | `/api/events` | **SSE-поток** обновлений заданий |

### Файловый менеджер
| Метод | Путь | Описание |
|-------|------|---------|
| `GET` | `/api/fm/list?path=` | Содержимое папки |
| `POST` | `/api/fm/upload?path=&conflictMode=replace\|skip\|rename` | Загрузка файлов |
| `POST` | `/api/fm/check-conflicts?path=` | Проверка конфликтов имён до загрузки |
| `GET` | `/api/fm/download?path=` | Скачать файл |
| `POST` | `/api/fm/rename` / `move` / `mkdir` / `zip` | Операции |
| `DELETE` | `/api/fm/delete` | Удаление |
| `GET` | `/api/fm/preview?path=` | Превью (стрим с Range) |
| `GET` | `/api/fm/search?q=` | Поиск по имени |

### Push / Пользователь
| Метод | Путь | Описание |
|-------|------|---------|
| `GET` | `/api/push/vapid-key` | Публичный VAPID-ключ |

| `GET` | `/api/me` | Профиль: квота, занято, права |

### Расширение (Bearer-токен)

|-------|------|---------|
| `POST` | `/api/add-ext` | Загрузка из расширения |

| Метод | Путь | Описание |

## Деплой

```bash
# Полный деплой кода (модули + sw.js + package.json + npm install + pm2 restart)
node deploy.js

# Деплой расширения (zip + загрузка на сервер)
node deploy_ext.js
```

Конфиг подключения — `deploy.config.js` (в `.gitignore`):
```js
module.exports = { host: 'IP', port: 22, username: 'root', password: '...' };
```

На сервере: PM2-процесс `vps-downloader`, логи `pm2 logs vps-downloader`.
